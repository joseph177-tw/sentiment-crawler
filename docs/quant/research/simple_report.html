簡化版策略 S 與逐步拆解

重點結論

  1. 簡化版 S 表現比原 C 版差，也沒贏過股票池等權。全期（2022/01 至今）扣成本後年化 11.5%，股票池等權 14.4%，原 C 版（同樣 60 日＋緩衝）23.0%，市值加權指數 27.2%。不論在原樣本外（7.0% 對 15.5%）還是原樣本內（15.1% 對 23.4%），S 都輸給 C。S 的五分組也沒有由低到高排列（全期 8.8%、15.4%、12.9%、12.9%、13.1%），代表它無法穩定排出好壞。
  2. 影響最大的是拿掉「接近 120 日高點」。逐步拆解中，這一步讓全期年化從 19.8% 掉到 13.5%（−6.3%），原樣本內更是從 23.6% 掉到 12.1%。它的 IC 在樣本外不顯著，但在組合裡扮演關鍵角色：外資持股和低風險因子偏向防禦型、金融股，接近高點是唯一能讓組合跟上漲勢的元件。少了它，組合在上漲行情中年化只有 22.6%，原 C 版是 39.7%、等權是 34.0%。
  3. 券資比在組合裡是減分的。它單獨的 IC 通過了樣本外檢驗，但加進組合後，全期從 13.5% 降到 11.5%，原樣本外從 10.9% 降到 7.0%。「單一因子 IC 顯著」不等於「加進組合會變好」：它和其他因子的資訊重疊，或者改變了選股的分布，都可能讓組合變差。
  4. S 也沒有比較抗跌。在下跌行情中，S 年化 −24.1%，原 C 版 −20.2%，指數 −19.2%。只有 2022 全年，S 的 −4.1% 略好於 C 的 −6.7%。拿掉動能因子並沒有換到更好的防禦力。
  5. 行情濾網和外資買超的影響比較小，方向也不一致。拿掉濾網，全期 −1.8%，但原樣本內反而 +2.2%。再拿掉外資買超，全期 −1.4%。兩者的貢獻都不大。「外資持股＋低風險＋接近高點、不加濾網」這個三因子版本，全期 19.8%、夏普 1.40、最大回撤 −18%，是拆解中回撤最小的版本。

整體判斷：這次簡化失敗了，原因是只看單一因子的 IC，卻忽略了因子在組合裡的分工。真正值得留下的候選有兩個：原 C 版（60 日＋緩衝），報酬最高；三因子無濾網版，最簡單、回撤最小。但這些比較已經用掉了 2022–2026 的全部資料，這頁沒有任何一個數字是樣本外的。我已經把這兩個版本加上 S 的目前名單存檔，接下來只能用新資料做前瞻追蹤來判斷，建議至少累積 2～3 個換股週期（約半年）。
